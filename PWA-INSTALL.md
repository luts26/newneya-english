# Встановлення та автономна робота

## Публікація

Розмістіть вміст цієї папки на будь-якому статичному HTTPS-хостингу.
PHP, база даних, npm і збірка не потрібні. Головна сторінка — index.html.
Працює і в корені домену, і в підпапці. Не відкривайте через file://.
Для перевірки на комп'ютері: `python3 -m http.server 8080`, потім http://localhost:8080.
HTTP за локальною IP-адресою з телефону не забезпечує Service Worker — потрібен HTTPS.

## Android

1. Відкрийте адресу в Chrome з інтернетом.
2. Дочекайтеся напису «Готово до роботи офлайн».
3. Натисніть «Встановити» або виберіть встановлення додатка в меню Chrome.
4. Закрийте вкладку, увімкніть режим польоту й відкрийте додаток з іконки.

## iPhone

1. Відкрийте адресу в Safari з інтернетом.
2. Дочекайтеся напису «Готово до роботи офлайн».
3. «Поділитися» → «На початковий екран» (Add to Home Screen).
4. Відкрийте додаток з іконки один раз онлайн і дочекайтеся готовності офлайн.
5. Перевірте в режимі польоту.

## Що працює без сервера

Слова, уроки, граматичні підказки, форми дієслів, статистика та налаштування.
Усі навчальні JS-файли, CSS, зображення й головна сторінка кешуються під час встановлення Service Worker.
Запити збереження до PHP видалені, зовнішній CDN іконок замінений локальними символами.
Прогрес лишається в localStorage цього браузера/додатка. Синхронізації між телефонами немає.
Очищення даних браузера може видалити прогрес і офлайн-кеш; після цього потрібне повторне завантаження онлайн.

## Озвучення

Використовується Web Speech API з мовою en-US та пріоритетом локального англійського голосу.
Для автономного озвучення завантажте англійський голос у налаштуваннях синтезу мовлення телефону.
Доступність голосу залежить від ОС і браузера; перевірте окремо в режимі польоту.
Текстові тренування не залежать від озвучення.

## Оновлення

Після змін JS/CSS/даних змініть CACHE у sw.js, наприклад learn-english-v1 → learn-english-v2.
Додайте нові ресурси в ASSETS. Опублікуйте всі файли одночасно.
Відкрийте додаток онлайн, закрийте всі його вкладки/вікна й відкрийте знову.
Новий Service Worker активується після закриття старих вікон. localStorage не очищається.
Не використовуйте однаковий префікс кешу для кількох копій додатка на одному домені.

## Перевірки цієї версії

Перевірено синтаксис JS, наявність усіх ресурсів із ASSETS, обробку офлайн-запитів Service Worker
та локальне збереження прогресу без серверного fetch у тестовому середовищі Node.js.
Повний запуск у мобільному браузері в цьому середовищі не перевірений — перевірте кроки вище на телефоні.
